OnePlus 13 — iOS 27.2 / 24B119 RAM quickstart
Documentation updated: 2026-11-05
===========================================

This branch describes the iOS27 status-layout-v4 profile. It does not use
the iOS16 GLES/Wi-Fi/Sileo payload. Other versions have their own branches.

Apple system images, firmware/calibration, SDKs and compiled artifacts are
not included. Supply the matching prepared local files; this is source-only.
Source/build requirements: source/ios27/README.md.

Boot in the original local workspace
------------------------------------
Start Android, enable USB debugging, authorize this Mac and connect USB.
The local runner is configured for the owner's phone serial and board sun;
adapt SERIAL for another device. Use Python3.11+, adb and fastboot on PATH.

/opt/homebrew/bin/python3 ~/Documents/Porting/OnePlus13-iOS-RAM/experimental/ios27/v2/boot-ios27.py

Its local BOOT-PREFLIGHT.json selects:
  UEFI:   experimental/ios27/v2/project-boot-ios27.img
  Payload:experimental/ios27/v2/status-layout-v4/payload.bin
  Boot:   experimental/ios27/v2/status-layout-v4/boot.apfs
  System: experimental/ios27/v2/system-registration-test.apfs

The runner uses fastboot boot only, stages matching images into RAM, starts
iOS and captures local phone-*/live-*.log files. It never flashes or erases
phone partitions. Keep USB connected until upload/startup finish. --menu is
not implemented. Do not mix these files with iOS16 or iOS19 images.

Status
------
Tested: native Metal UI, lock/home screen, touch, seven iOS cores, native
battery and charging/unplug/reconnect reporting. User confirmed Dynamic
Island alignment, battery placement and wallpaper display.
Unfinished: clock visibility, wallpaper selection, blank widgets, animation
black bands and broader app compatibility. 60/120FPS is not established.
Wi-Fi is disabled; sound is unverified and Voice Memos reportedly froze.
The CPU-governor trial was rejected and is not the selected kernel.

After startup you can unplug USB; iOS continues in RAM until reboot.
To return to Android while firmware USB responds:
fastboot -s xnuloader oem reboot

Use a cold reboot before another GPU/DSP session. Do not reuse oem stop;
a shutdown panic was observed. If USB is unresponsive, hold Power + Volume
Up until restart, let Android finish loading, then run the boot helper again.

Read live logs only after the host helper finishes, using one USB client:
fastboot -s xnuloader oem log
fastboot -s xnuloader get_staged ios27-live.log

Keep system.apfs and all Apple/runtime images, firmware/calibration and raw
logs out of GitHub. See BUGLIST.txt and validation/ios27/STATUS.json.
