iOS19 branch — source checkout notes
===================================

This repository does not contain Apple images, firmware, calibration or
compiled boot artifacts. The local-workspace commands below require those
prepared local directories and are not standalone checkout builds.

From this checkout, build the source helpers with your local SDK:
python3 source/ios19/tools/build-compat.py --output build/ios19-root --bootstrap

To use a prepared, private iOS19 profile with the portable runner:
python3 source/ios19/tools/boot-ios19.py --profile /path/to/BOOT-PREFLIGHT.json --serial YOUR_SERIAL --check
python3 source/ios19/tools/boot-ios19.py --profile /path/to/BOOT-PREFLIGHT.json --serial YOUR_SERIAL

Python 3.11+ is required. --check verifies hashes without contacting the
phone. Keep the system, payload and UEFI from the same profile. Full source
and local-input requirements: source/ios19/README.md.

The following guide records the owner's original prepared workspace layout.
For another machine, adapt the paths and serial; the compiled files remain
local inputs. The iOS19 branch's current snapshot is verified-slider-v6.

OnePlus 13 — iOS 16, iOS 27 and iOS 19 RAM boot
Updated: 2026-11-05
================================================

All three boots run from RAM. Use fastboot boot only to load UEFI.
Never flash or erase phone partitions. A cold reboot loses the uploaded
system, installed packages and changed settings; upload again to boot iOS.
Do not mix a version's UEFI, payload or system image with another profile.

Before any boot
---------------
1. Start Android, enable USB debugging, connect USB and authorize this Mac.
2. Keep adb and fastboot on PATH. Use /opt/homebrew/bin/python3 (Python 3.11+
   is required by the iOS 27/19 runners; the macOS system Python is too old).
3. Check the connection: adb devices
   This phone's serial: YOUR_SERIAL; Android platform: sun.
4. Choose ONE command below. The helper reboots Android to the bootloader,
   loads UEFI with fastboot boot, uploads the matching images and starts iOS.
   Keep USB connected until uploading and startup have finished.

A UEFI screen alone does not contain iOS: the Mac must upload the RAM images.
The iOS 27/19 runners already contain this phone's serial; edit SERIAL in
that runner when using a different device. They create dated phone-* logs.

For a later boot from an existing iOS session, return to Android first.
Do not reuse a stopped GPU/DSP session or use oem stop for another boot.

Choose your version
-------------------

During any RAM session
----------------------
After startup you may unplug USB; iOS keeps running while the phone stays on.
USB must be connected for host diagnostics. Reconnection behavior is only
verified for profiles where it has actually been tested; these are firmware
fastboot diagnostics, not an iOS SSH/file shell.

After the boot helper has finished, read live logs with ONE host client:
fastboot -s xnuloader getvar result
fastboot -s xnuloader oem log
fastboot -s xnuloader get_staged ios-live.log

Do not issue concurrent commands while a boot/upload/log helper owns USB.
If software reboot or USB stops responding, hold Power + Volume Up until
restart, let Android finish loading, then run the chosen boot command again.

Apple system images, IPSWs, firmware, private calibration and raw logs stay
local. Do not add system.apfs or any other Apple system image to GitHub.
